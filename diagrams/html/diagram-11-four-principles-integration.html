Diagram 11 — Four Principles Integration: The EM Data Product as a Coherent System
Principle 1
Domain Ownership
Fishery Monitoring domain owns the EM data product lifecycle — from raw video ingestion through species ID, quality control, and publication. DPO coordinates a virtual team spanning six science centers.
Section 5.1 • MSA sec.403
Principle 2
Data as a Product
EM Data Contract: Schema v1.2, Completeness SLO >99%, Species ID Accuracy >95% family / >90% species, Timeliness <30 days. Row-level access controls enforce MSA confidentiality.
Section 5.2 • Dehghani, 2022; Perrin & Broda, 2024
Principle 3
Self-Serve Platform
Terraform template automatically provisions BigQuery datasets, IAM policies, Data Catalog entries, Dataplex quality rules, and Cloud Monitoring SLO dashboards. DPO promotes via CI/CD pipeline.
Section 5.3 • BigQuery, Cloud Run, Data Catalog, Dataplex, Cloud Build
Principle 4
Federated Computational Governance
MSA sec.402(b): Row-level security in BigQuery. NIST 800-53: AC-3, AU-2, SC-7, SI-10, SC-13 inherited via platform. 60–70% of controls covered by platform ATO.
Section 5.4 • Cloud IAM, VPC Service Controls, Cloud DLP, Cloud KMS
